AKSHAYPATRA FOODS WEBSITE – FREE HOSTING STARTER

Files:
- index.html: complete responsive website and WhatsApp order form
- products.js: product catalogue and pack-size prices

WhatsApp orders:
The site is configured to send customer orders to +91 89760 66676.
Customers review and send the prepared message in WhatsApp; the site does not
silently send messages.

Before publishing:
1. Open products.js in a text editor.
2. Add your actual product names, descriptions, pack sizes and prices using
   the example format in that file.
3. Save both files in the same folder.
4. Open index.html in a browser to test.
5. Publish the folder using GitHub Pages (free) or Netlify Drop (free tier).

Free publishing with GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a public repository named akshaypatra-foods-website.
3. Upload index.html and products.js to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. GitHub will provide a free https://<username>.github.io/akshaypatra-foods-website/ address.

No hosting subscription or paid domain is required. A custom domain is optional
and may cost money. The website has no online payment gateway or database:
orders are sent to WhatsApp, and the owner manages them there.
